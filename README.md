# Integration of MongoDB & Mongoose with Node.js and Express.js

**Use Case:** KJS-HC-03 Urine Test Strip Reader using Colorimetry as a Point-of-Care Technology

## Overview
This repository contains the complete implementation for Experiment 6 of the Web Programming Laboratory (WPL). It showcases:
1. **MongoDB Shell Operations**:
   - `insertMany`: Inserting structured urinalysis test results (analyte readings for glucose, protein, pH, device ID, clinician notes).
   - `find`: Document retrieval with projection and criteria filtering.
   - `updateOne` & `deleteOne`: Document modification and removal.
   - **Comparison Operators**: `$gte`, `$ne` evaluating physiological threshold limits.
   - **Logical Operators**: `$and`, `$or` multi-condition clinical triage queries.
   - **Projection**: Selective field extraction for report generation.
2. **Student Application Form**:
   - Node.js & Express.js backend storing student admissions and test operator credentials directly into MongoDB.
